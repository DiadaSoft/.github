# Díada

Sistema en la nube para pequeñas empresas manufactureras en Colombia.

**Qué hace**
- Inventario de materias primas y producto terminado
- Producción por fórmula, con control de consumo de materiales
- Pedidos, despachos y cartera de clientes
- Alertas de stock y reportes del periodo

Cada empresa trabaja en su propio espacio, con sus datos separados.
